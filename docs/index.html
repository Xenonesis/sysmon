Capabilities

A focused toolkit for the machine under the desk.

SysMon is built for developers, sysadmins and power users who want hard numbers, clearly shown. Each panel is a first-class tool — no bloat, no telemetry, no cloud.

TelemetryHub

Multi-Tier Telemetry Architecture

Dedicated background engine separating 60 FPS UI rendering from 1–5 Hz hardware sampling. Includes vendor-independent provider abstractions and bounded multi-resolution ring buffers.

Process forensics

Trace exact executable paths, command lines, and working directories. Safely terminate sub-trees with integrated audit history.

Deep GPU metrics

Monitor VRAM, core clocks, and power draw via NVIDIA NVML or native Windows fallback for vendor-neutral GPU telemetry.

Diagnostics

Evidence-based insights

Automated findings with confidence ratings, plus opt-in local JSONL session recording to track transient slowdowns. Nothing is uploaded.

Smart alerts & throttling

Configurable alert thresholds alongside a background polling scheduler that throttles 5x when minimized to conserve power.

Utility

RAM cleaner — manual & automatic

Free memory on demand or automatically. Auto-clean is fully configurable: trigger threshold (down to 1%), target level, min interval, per-pass MB cap (up to 16GB), idle-only gating, Smart Clean (ignore active apps), excluded processes, and freed-MB notifications. Now with global Ctrl+Alt+C hotkey support.

Startup manager

Review and toggle Windows startup entries by name, publisher and boot-time impact.

WMI system info

Motherboard, BIOS version, GPU driver, OS build, battery health and power state — one place.

Services manager

Browse every Windows service by display name and state, colour-coded at a glance.

Power plan toggle

Switch installed Windows power schemes from the tray — no Control Panel needed.

New

Desktop mini-widget

A compact always-visible overlay with live CPU, RAM, GPU and network — toggled from Settings.

Verified auto-updates

Checks GitHub every 24 h. Updates download only on explicit approval, after URL, size and Authenticode signature checks.

Snapshots & export

Export the current system state to CSV, JSON or a redacted diagnostics report for scripts and support.

Per-core CPU view

Utilisation and thermal breakdown for every logical core, so you can see the real load.

Release notes

What's new in v3.7.0

A full TelemetryHub architecture with provider abstraction, evidence-based diagnostics, guarded system actions and a signed supply chain.

TelemetryHub architecture

Multi-tier telemetry hub on dedicated background threads decouples 60 FPS UI rendering from 1–5 Hz hardware sampling. Polling scheduler throttles 5x when minimised to conserve CPU and power.

Provider abstraction

Vendor-independent TelemetryProvider trait (Sysinfo, NVML, WMI). Bounded 60s / 5m / 30m / 1hr ring buffers with current, min, max and average statistics. Individual provider failures never take down main telemetry.

Vendor-neutral GPU

Windows GPU adapters and performance counters complement detailed NVIDIA NVML metrics — Intel, AMD and other Windows GPUs now covered.

Diagnostics workspace

Evidence-based findings with confidence ratings, plus opt-in local JSONL session recording to reproduce transient slowdowns. Nothing is uploaded.

Polling scheduler

Throttles polling 5x when minimized to conserve CPU and power, ensuring minimal footprint.

Graceful error isolation

Independent provider failure handling — missing WMI or NVML no longer affects main telemetry.

Safe action plans

Risk previews, elevation disclosure, confirmation, and local audit history with Undo for known reversible operations.

Signed supply chain

Signed release workflow with cert pinning, checksums, SPDX SBOM, and Windows CI quality gates on locked dependencies.
