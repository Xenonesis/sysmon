Capabilities

A focused toolkit for the machine under the desk.

SysMon is built for developers, sysadmins and power users who want hard numbers, clearly shown. Each panel is a first-class tool — no bloat, no telemetry, no cloud.

TelemetryHub

Multi-Tier Telemetry Architecture

Dedicated background engine separating responsive UI rendering from 1–5 Hz hardware sampling. Includes vendor-independent provider abstractions and bounded multi-resolution ring buffers.

HUD

Floating Desktop HUD

Always-on-top precision mini-widget (toggled via Ctrl+M or header icon) showing live CPU, RAM, GPU, disk throughput, network rates, and quick-clean memory.

Sockets

Active Network Sockets

Real-time TCP/UDP socket table with live PID resolution, process name mapping, and connection state filtering (ESTABLISHED, LISTEN, TIME_WAIT, CLOSE_WAIT).

Process Pro

Process Tree & Disk I/O

Hierarchical parent-child process tree mode, real-time per-process disk read/write bandwidth, CPU core affinity controls, and kill-tree forensics.

Storage

Storage S.M.A.R.T. Health

Physical drive auto-detection (NVMe SSD, SATA SSD, USB) with live S.M.A.R.T. health status, drive type classification, and partition usage.

Diagnostics

Diagnostics & CSV Export

Automated findings with confidence ratings, local JSONL session recording, and 1-click CSV session export with aggregate statistics.

Deep GPU metrics

Monitor VRAM, core clocks, and power draw via NVIDIA NVML or native Windows fallback for vendor-neutral GPU telemetry.

Utility

RAM cleaner — manual & automatic

Free memory on demand or automatically with native WorkingSet quota APIs. Configurable trigger thresholds, per-pass caps, exclusions, and global Ctrl+Alt+C hotkey support.

Power

Battery & Power Plans

Real-time battery charge percentage, AC power status, and 1-click switcher between Windows power schemes (Balanced, High Performance, Power Saver).

Verified auto-updates

Checks GitHub every 24 h. Updates download only on explicit approval, verified with SHA-256 checksums and GitHub build provenance.

Spec sheet

Runs comfortably on everyday hardware.

SysMon stays out of the way, leaving the rest of your system free to do real work.

System

  • Windows 10 / 11 — 64-bit
  • ~5 MB installer · ~8 MB disk footprint
  • Configurable 1–10 s refresh (2 s default)
  • Runs in the system tray

Optional hardware

  • NVIDIA GPU for deep NVML metrics (VRAM, clock, power, fans)
  • Motherboard / BIOS telemetry on supported boards
  • Battery / AC power sensing on laptops

Notes

  • Advanced process control & RAM cleaning may request administrator privileges
  • Fully offline — no cloud, no telemetry
  • Open source under the MIT License

Release notes

What's new in v3.7.7

Reversible startup quarantine, exact Windows target selection, correct process trees and more reliable alert and service actions.

Reversible Startup Quarantine

Startup entries are backed up locally before removal and can be restored from persistent system action history.

Exact Windows Targeting

Registry hives and keys, startup-file paths, and scheduled task paths are retained so duplicate names stay isolated.

Correct Process Trees

Process Manager now uses actual parent PIDs and preserves ancestor context when filtering the hierarchical view.

Consistent Alerts

In-app alerts work independently of desktop notifications and disk alerts honor the configured threshold.

Safer Service Restarts

Windows state, checkpoints and wait hints drive bounded restart waits with explicit partial-failure reporting.

Supply-Chain Hardening

Immutable GitHub Action pins, scheduled RustSec scans and automated dependency update checks.
